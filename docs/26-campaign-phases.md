# Fases de campaña

Las campañas pueden organizarse en fases reutilizables:

- Intriga.
- Anuncio.
- Deseo.
- Conversión.
- Urgencia.
- Personalizada.

Cada fase define objetivo, inicio, cierre y canales previstos. Sus fechas deben quedar
completamente dentro de la campaña.

El panel compara las tareas editoriales con las ventanas de cada fase y alerta cuando
una etapa no tiene publicaciones previstas. La fase no publica ni programa por sí sola.

La base Supabase preparada incluye `campaign_phases`, RLS por organización y una
validación de fechas contra la campaña. No se aplica a un proyecto remoto hasta
destrabar la infraestructura y aprobar el merge.
