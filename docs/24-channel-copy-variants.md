# Variantes de copy por canal

Cada pieza conserva un copy base y puede definir una variante manual para cada canal
seleccionado:

- Instagram.
- Facebook.
- TikTok.
- YouTube.
- WhatsApp.
- MasAlto.com.ar.

Si una variante queda vacia, la tarea utiliza el copy base. El CSV editorial exporta
el texto efectivo de cada tarea.

Esta funcion no usa IA ni publica contenido. Una integracion futura podra proponer
variantes, pero siempre debera conservar la aprobacion humana antes de cualquier salida
externa.
