# Registro de eventos publicos

El catalogo de `eventos.masalto.com.ar` consume un registro publico separado del
workspace local de demostracion.

Cada evento publicado define:

- Identificador y slug unicos.
- Nombre, fecha y lugar.
- Estado de venta.
- Flyer, hero e imagen social.

Todos los eventos comparten el catalogo principal. Cada slug conserva su propia ficha
y puede tener una direccion visual especifica, como la landing aprobada de Sabroso.

Cuando exista un segundo evento confirmado, se agrega al registro junto con sus assets
y su landing. No se reutilizan automaticamente flyers ni imagenes de otro artista.
