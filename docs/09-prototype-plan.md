# Plan del prototipo

## Objetivo

Crear una primera experiencia navegable para validar el flujo central de MasAlto Social Hub antes de conectar integraciones reales.

## Pantallas del prototipo

### 1. Dashboard

Debe mostrar:

- Campanas activas.
- Eventos proximos.
- Publicaciones programadas.
- Consultas abiertas.
- Leads captados.
- Sorteos activos.
- Estado Accred cuando exista vinculacion.
- Alertas operativas.

### 2. Evento

Debe permitir visualizar:

- Datos generales.
- Modo: independiente o vinculado con Accred.
- Modulos Accred activos.
- Estado web.
- Estado de venta.
- URL publica.

### 3. Campana

Debe mostrar:

- Objetivo.
- Publico.
- Concepto creativo.
- Presupuesto.
- Fases.
- Contenidos relacionados.

### 4. Calendario

Debe mostrar:

- Publicaciones por dia.
- Canal.
- Estado.
- Formato.
- Accion requerida.

### 5. Automatizaciones y sorteos

Debe mostrar:

- Palabras clave.
- Respuestas aprobadas.
- Participantes.
- Ganadores.
- Derivaciones pendientes.

### 6. Publicacion web

Debe mostrar:

- Preview de pagina en `masalto.com.ar`.
- SEO.
- Estado de venta.
- CTA.
- Modo de checkout: externo, Accred headless o subdominio transitorio.

## Datos mock iniciales

Evento piloto:

- Nombre: Sabroso en San Juan.
- Fecha: 28 de agosto de 2026, 23 h.
- Venue: Hugo Espectaculos.
- Modo: vinculado parcial con Accred preparado.
- Web: programada.
- Venta: preventa.

Campana:

- Concepto: Del lado correcto de la noche.
- Objetivo: venta de entradas y reconocimiento local.
- Canales: Instagram, Facebook, TikTok, WhatsApp y web.

## Validacion del prototipo

- El usuario entiende si un evento esta o no vinculado con Accred.
- El usuario entiende que `masalto.com.ar` es la salida publica.
- El usuario puede distinguir datos sociales de datos operativos.
- El flujo no sugiere que Accred este conectado si solo hay mocks.
- La interfaz mantiene aprobacion humana para publicaciones y automatizaciones.
