# Exportacion manual de publicaciones

El calendario editorial puede descargar un CSV para trabajar con publicaciones
asistidas sin conectar credenciales sociales.

El archivo incluye:

- Fecha programada.
- Canal y estado.
- Campaña y titulo interno.
- Formato y copy.

La descarga no publica contenido ni envia datos a un proveedor. Las celdas que
podrian interpretarse como formulas se neutralizan antes de generar el archivo.

Este mecanismo es el respaldo operativo mientras la herramienta de publicacion
multired siga pendiente de eleccion y aprobacion.
